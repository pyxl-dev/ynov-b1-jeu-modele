# Attrape-fruits - dépôt modèle

Mini-jeu web (HTML, CSS, JavaScript) pour le cours Outils IA, Bachelor 1, Ynov. Il fonctionne déjà : tu vas l'améliorer avec GitHub Copilot, défi après défi.

## Démarrer

1. Clique sur **Use this template** puis **Create a new repository**. Nom conseillé : `jeu-ia`. Dépôt **public**.
2. Clone ton nouveau dépôt, ouvre le dossier dans VS Code.
3. Ouvre `index.html` dans ton navigateur (double-clic sur le fichier). Le jeu se lance : flèches ou souris pour bouger le panier.

## Les fichiers

| Fichier | Rôle |
|---|---|
| `game.js` | tout le jeu : réglages, état, logique, dessin, boucle |
| `index.html`, `style.css` | la page autour du jeu |
| `JOURNAL.md` | tes prompts et ce que l'outil a fait, un bloc par défi |
| `.github/copilot-instructions.md` | consignes que Copilot lit sur ton projet : adapte-les |

## Publier le jeu (défi 5)

Dans ton dépôt sur github.com : **Settings**, **Pages**, **Source : Deploy from a branch**, branche `main`, dossier `/ (root)`, **Save**. Après une à deux minutes, l'adresse du jeu apparaît en haut de la page : `https://<ton-compte>.github.io/<nom-du-depot>/`.

## Ce qui est évalué

Ton dépôt GitHub : commits, pull request, `JOURNAL.md`. Le lien du dépôt est à déposer sur Moodle à la fin de la séance. Le détail des défis est dans le sujet donné en cours.
